# 🎮 AI Shoutcaster
Welcome to **AI Shoutcaster** — an end-to-end system that generates live-style commentary for Valorant matches using advanced computer vision and language models.

## 🔥 Product Description
- Extracts frames from gameplay.
- Detects agents and actions using YOLOv8.
- Generates tactical commentary with LLaVA-7B.
- Optionally produces TTS voiceover and video output.
